║                     AGENT DISPATCHER INFRASTRUCTURE ROLE                               ║
╚════════════════════════════════════════════════════════════════════════════════════════╝

Agent Dispatcher is a FRAMEWORK LAYER that MANUS uses:

    MANUS (Agent Implementation)
          │
          ├─ Uses AgentInstance from agent_dispatcher
          ├─ Uses AgentTemplate from agent_dispatcher
          ├─ Uses Skill definitions from agent_dispatcher
          └─ Integrates MCP tools via agent_dispatcher
                   │
                   ▼
    AGENT DISPATCHER (Infrastructure)
          │
          ├─ Domain Model
          │  └─ Plan/Action/Skill/MCP
          │     ├─ MCPEngine (tool invocation)
          │     └─ Skill conversion
          │
          └─ Infrastructure
             ├─ Entity Definitions
             │  ├─ AgentInstance (template + config)
             │  ├─ AgentTemplate (skills + metadata)
             │  ├─ Skill (tool definition)
             │  └─ SkillFunction (tool wrapper)
             │
             └─ Utilities
                ├─ count_token
                ├─ regex_util
                ├─ time_util
                └─ constants
